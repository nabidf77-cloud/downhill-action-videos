# Downhill Action Videos

Vertical (9:16) downhill action videos. All clips are 720p / 24fps / ~10 seconds, clean runs — driver/rider in control throughout, no crashes.

## Gravity Cart — Durian Grove Run

Handmade teak gravity cart (3-wheel trike) bombing a steep jungle dirt track in a tropical durian grove — 75-degree hairpin, pendulum drifts, dust curtains, golden sunbeams.
